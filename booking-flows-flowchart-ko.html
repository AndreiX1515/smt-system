핵심 정리
1. 날짜 변경: 기존 예약의 departureDate는 절대 직접 UPDATE되지 않음. 날짜 변경 기능 없음.
2. 결제 유형: ≤34일 Full(1단계), 35~44일 Middle(2단계), >44일 Staged(3단계). staged↔middle 자동 변환
3. 34일 규칙: 출발 34일 이전 → 여행자 직접 수정, 34일 미만 → pending_update 승인 필요 (edit_allowed 플래그 예외)
4. 선차감: 인원 증가 시 승인 전에 인원/금액 즉시 반영 (좌석 선점), 거절 시 자동 복원
5. 자동 프로세스: Cron 02:00 check_reject 자동 복구(3일), Cron 03:00 waiting_cancelled 자동 취소(24시간)
6. 기한 연장: 분할 결제(staged/middle) + 출발 31일 이상 + 미연장 상태에서만 1회 가능 (+3일)
7. Capacity: adults + children + infantsWithSeat 합산, cancelled/refunded 제외, FOR UPDATE 동시성 보호
